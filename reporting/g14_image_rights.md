**Use disposition:** rights-cleared candidate for a specifically captioned 2026 Nashik flood/recovery visual. Suitable in a section that explicitly explains different places and indicators moved in different directions. Do not use as the background for a nationwide shortage headline, or imply it documents a September 2026 condition. A photo alone does not prove the claimed dam discharge; if that causal sentence is needed, verify it separately. Check visual crop and image credit on mobile as well as desktop before deployment. Keep an exact file-page link and license notice in both HTML and portable ZIP.

**Resize versus adaptation:** CC BY-SA 4.0 [section 2(a)(4)](https://creativecommons.org/licenses/by-sa/4.0/legalcode) allows technical modifications necessary for media/format display and says those alone do not produce adapted material. A straight 1280-pixel thumbnail is a technical resize; label it as such for transparency. A meaningful crop, retouch or color treatment may be an adaptation depending on copyright law; treat such derivatives as CC BY-SA 4.0 and label each change. Merely placing the unaltered photo next to independently written site text should not make the entire site CC BY-SA. Avoid adding any misleading image overlay or implying licensor endorsement.

## Permission route and next action

1. The implementation/design team may use the exact Nashik Commons image with the full linked credit and date-specific caption above, retaining the CC BY-SA terms and giving the adapted file its own change notice if resized/cropped/color-graded. It should remain a counterpoint to shortage claims.
2. For a present-tense shortage/farmer photograph or news clipping, identify the photographer/rights desk on the original story and request **written** permission specifying the exact file, public GitHub Pages and portable ZIP redistribution, worldwide term, commercial/noncommercial scope, crop/animation/social previews, attribution, and any model-release limits. Contact requires publisher authorization; none was sent.
3. Recheck the live file description and source link at release time. Store a snapshot/hash of the exact deployed derivative and its attribution next to the public asset. Do not make rights-cleared picture metadata into a public water-condition measurement.

## Source and method limits

The Commons file page, original file and API support authorship/licensing as represented by the uploader, image identity and declared date/place. Wikimedia itself warns that it does not warrant the accuracy of each file's copyright status; this review checked consistency with embedded metadata, but cannot independently establish chain of title beyond the author-uploader's assertion. The [CC BY-SA 4.0 deed](https://creativecommons.org/licenses/by-sa/4.0/) states attribution/change/ShareAlike terms and warns that privacy/publicity rights may remain. This audit is not legal advice and did not review every current 2026 photograph online.
