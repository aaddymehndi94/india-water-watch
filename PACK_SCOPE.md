# What this delivery is
This is a Codex execution starter, not the site, not a drought dataset, and not finished investigative reporting.

It includes a complete reporting/product/engineering assignment, native agent role configuration, a 30-task graph, an acceptance matrix, 9 record schemas, source-discovery and technical reference registries, prompt-driven workflows, persistent state, testable reference logic and a fail-closed structural release gate.

No sources have been promoted into production observations. The source registry records what was inspected, what failed access and what is only a lead. Current numerical claims and historical rankings require new direct source verification by the implementation/reporting workflow. Sources listed as inspected refer to the stated landing/catalogue/documentation scope, not validation of unseen datasets.

The small Python checks are runnable now. The production JavaScript application, ingestion adapters, newsroom articles, chart/map components, full-schema validator, browser tests and deployment workflows are assignments for Codex. Their specified commands are not already implemented here.

This package contains no production `dist/`, no account credentials, no external-service calls on opening, no active CI schedules and no public deployment authorization. The prior HTML is deliberately excluded. Test fixtures are temporary arithmetic/structural examples and cannot be used as observed data.
