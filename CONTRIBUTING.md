# Contributing
The site is an independent publication, not an official alerting service. Changes need scoped tasks, reproducible evidence and review. A new source or dataset must satisfy the source adapter and rights contracts before appearing publicly.

For factual corrections, identify the public URL, claim or chart, observed issue, exact supporting source and relevant date/geography. Do not post personal identifiers, private addresses, medical details, unpublished interview notes or source credentials in public issues. A publisher-approved private contact route must be configured before collecting sensitive tips.

Code/data contributions must include appropriate tests and state whether records are measured, estimated, derived or synthetic. Never add synthetic observations to production stores. Keep generated output out of source control unless the chosen deployment profile explicitly needs it. Formatting-only changes must not modify historical evidence or refresh observation timestamps.

Respect the distinction between agent review, specialist consultation and human publisher approval. Contributors must not invent biographies or claim affiliations with source institutions. Third-party rights are described in RIGHTS.md, not superseded by the repository's MIT license.
